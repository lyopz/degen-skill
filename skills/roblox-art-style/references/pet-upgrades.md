# Upgrading a part or body: "10,000x cooler" (lyopz, 2026-10-25)

<!-- from: lyopz (2026-10-25): "for the upgrades thats just when i want to update something in the accessories or body / base so 10,000x cooler just has a rough understanding what i mean in depth". -->

Use this **only when lyopz asks to upgrade an existing accessory or base body.** It doesn't add new items. The result is the same item, just much more epic.

## Steps (same item, each step adds on top)
1. **Base:** the clean model, no effects. **Keep this shape**; never redesign it.
2. **Light animation:** soft inner glow + subtle movement (gentle flap, float, pulse).
3. **Auras:** particles, trails, floating shards around it.
4. **Depth:** multi-layer effects: orbiting rings, energy ribbons, extra floating elements, transparent layers.
5. **10,000x cooler:** all layers together, with more colours/gradients, more motion and full detail. It's still clearly the same item.

## Effect layers to pick from
base shape · inner glow · crystal layers · energy ribbons · orbiting rings · particles/sparks · runes/glyphs · light trails · aura field. Add secondary effects (rings, orbs, runes, trails) and multiple colours/gradients.

## Rules
- Same base shape, size and attach point, so it still fits every body and slot.
- More layers + motion = cooler, but keep it clean, readable and optimized for Roblox (low-poly budgets, ≤ 3 emitters per part, phone check). Glow on edges, cores and effects, never a blown-out sheet.
- Theme it with one element (void, ice, fire, toxic, storm, light, dark, rainbow, galaxy, celestial); colour variants of the same item are fine.
- Upgrade the animations too: idle (float + wave), walk (bob + sway), run (bigger movement), turn (flowing trail), jump (spread + burst), attack/skill (energy release), spin (full effect).
- Show lyopz the before/after side by side (front, 3/4, side, back, top).
