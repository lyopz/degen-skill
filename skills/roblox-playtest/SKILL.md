# Roblox Playtest (look and learn)

## Hard rules
- **Never** click Buy, Purchase, Confirm, Robux, Premium, Gift, Trade-accept, or any price button that opens a purchase prompt. If a purchase prompt appears, press **Cancel/X** immediately and note it.
- Never enter passwords, never change account/privacy settings, never chat or friend people, never join voice.
- Only games lyopz names or approves. Stop when he says stop.
- Computer use asks lyopz for access to the Roblox app first (request_access). Keep sessions short; tell him what you're doing in one line.

## How
1. Open the game lyopz named (Roblox app). Wait for load; screenshot.
2. Controls: WASD to move, Space to jump, mouse drag (right-click) to turn the camera, scroll to zoom, E/F for prompts, click UI buttons. Short key holds (0.5–2 s), then screenshot.
3. Tour in this order: spawn view → HUD → each menu (inventory, pets, quests, settings) → shop (look only: read tabs, products, prices, layout) → eggs/hatching (free ones only, with in-game currency) → zones/gates → anything special.
4. Note numbers (prices, rates, odds), layout, feel, effects. Screenshot key screens into `~/RobloxGames/studies/<game>/`.
5. Write findings with `roblox-game-strip` section 2 → file them per its section 3 (shops → `roblox-shops/studies/<game>.md`).

## With lyopz
He plays, we watch and comment: ask what to look at, call out patterns ("their shop opens from the left stack, 4 tabs, featured card on top"). Or we drive and he watches.
