# Saved styles

Looks lyopz liked, saved from the Degen Roblox app's **Save for later** tab. He names each one.

Each folder `styles/<name>/` has:
- `style.md` — what he likes about it, the pictures, and the look (shapes, palette, rules).
- `prompts.md` — the ChatGPT / Customuse prompts that made it, best rated first.
- `pic-*.png` — the pictures he picked.

Only what he keeps on the save page goes here. The rest of the game stays on his PC.
To use one, say "new game in my saved style <name>" (or press **Use for a new game** in the tab).
